Hoot Unfathomably Changelog
===========================

Unreleased
----------

Version 0.2.3
-------------

- Added a one-time Android notification onboarding prompt after the first
  account becomes active, using the same permission, baseline, and background
  task checks as the Settings toggle.
- Rebuilt the release test suite around explicit Unfathomably, Rebased, and
  Pleroma contracts for timelines, groups, discussions, reactions, accounts,
  OAuth, notifications, and persisted sessions.
- Removed retired server-version test matrices and added a strict,
  self-tested release check that prevents obsolete service imports and API
  routes from returning.
- Removed retired screens and conditional legacy tabs from the active
  navigation tree so the tested app surface matches the six current feeds,
  groups, posting, notifications, and options destinations.

Version 0.2.2
-------------

- Made FBXL Social an explicitly optional login shortcut and added validated
  custom server entry for Unfathomably, Pleroma, Rebased, and
  Mastodon-compatible hosts.
- Added browser-based OAuth authorization-code login on the selected server
  while retaining direct password login for servers that support it.
- Made account creation and password recovery open the currently selected
  server instead of using legacy Lotide or FBXL-specific routes.
- Restored the host-picker suite to the release gate and covered custom hosts,
  local development ports, saved-server isolation, OAuth callback validation,
  and unavailable-host behavior.

Version 0.2.1
-------------

- Fixed Android login failing after successful authentication because the
  generated Secure Store token key contained characters rejected by the native
  module.
- Added native-compatible Secure Store key validation to the test environment
  and restored the current Unfathomably login suite to the release test run.
- Kept server-handled registration from leaving the login form permanently
  disabled.
- Replaced the inherited Lotide notification poller with the
  Mastodon-compatible Unfathomably notifications endpoint.
- Migrated background notification settings to Hoot Unfathomably task,
  storage, and Android channel identifiers without alerting old history.
- Updated notification taps to open Unfathomably status discussions and
  removed stale Lotide labels and errors from notification settings.

Version 0.2.0
-------------

Initial public Hoot Unfathomably release.

- Reoriented the former Hoot Mobile client around the Unfathomably
  Mastodon-compatible API and its group extensions.
- Added Home, followed Group feed, Groups, New post, Notifications, and
  Options navigation.
- Added group discovery, membership, group timelines, and group posting.
- Added account timelines, threaded status views, replies, reposts, quote
  reposts, and server-supported emoji, positive, and negative reactions.
- Added notification loading and navigation to the relevant discussion.
- Added an accessible full-screen image viewer with zoom and pan support for
  long or text-heavy images.
- Stored authentication tokens in the platform secure store, migrated legacy
  local tokens safely, and require HTTPS for remote servers.
- Updated the mobile stack to Expo SDK 57, React 19, and React Native 0.86.
- Added strict static checks, unit tests, Expo diagnostics, production
  dependency auditing, Android release builds, and Android device smoke tests.

The previous Lotide-focused changelog was intentionally retired with this
project's public rename. This file records Hoot Unfathomably releases only.
